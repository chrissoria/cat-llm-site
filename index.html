CatLLM

A reproducible LLM pipeline
for classifying open-ended text

A Python and R toolkit for systematic text classification using large language models. Validated against expert human coders across 21 LLMs and 4 survey tasks (98% accuracy vs. human consensus). Provider-agnostic — runs on GPT, Gemini, Qwen, Claude, or fully local open-weight models via Ollama.

Design Principles

Designed for empirical research

Defaults grounded in systematic evaluation — so methodological choices are documented, defensible, and reproducible.

Multi-model ensembles

Aggregate predictions across models with unanimous voting. Inexpensive open-weight ensembles can match or exceed individual frontier models at a fraction of the cost.

Provider-agnostic

Compatible with GPT, Gemini, Qwen, Claude, and open-weight models served via Ollama. REST-based with no SDK dependencies; switch providers without changing analysis code.

Local-only deployment

Runs entirely on local hardware via open-weight models. Sensitive data — survey responses, clinical text, PII — never leaves the machine, supporting IRB and HIPAA constraints.

Unified multimodal interface

Text, images, and PDFs share one consistent API. Automatic input detection handles mixed datasets without per-modality configuration.

How it works

A three-stage
classification pipeline

From raw text to coded data — no predefined categories required.

01
Explore

Automatically discover categories from your data. Sample responses, let the model surface recurring themes, then merge semantically similar labels into a clean taxonomy.

02
Extract

Extract structured classifications at scale. Batch processing handles entire dataframe columns with configurable model selection and provider routing.

03
Classify

Assign categories with multi-label support and ensemble voting. Verbose definitions with inclusion/exclusion criteria dramatically reduce over-classification.

↓

↓
CLASSIFY Multi-label + ensemble vote

Ecosystem

Domain-specific packages

Each package includes optimized prompts, specialized parameters, and built-in data sources for its domain — while sharing a consistent API.

Example

From raw responses
to coded data

A complete classification pipeline in under 10 lines of Python. Works the same way in R via the reticulate wrapper.

✓
Multi-label support
One response can belong to multiple categories simultaneously.
✓
Automatic "Other" escape valve
Prevents forced miscategorization of ambiguous responses.
✓
CSV-ready output
Results export directly for use in Stata, R, or Python.
python
import cat_survey as cat # Step 1: Discover categories cats = cat.extract( input_data=df['responses'], survey_question="Why did you move?", n=50, api_key=api_key ) # Step 2: Classify at scale results = cat.classify( input_data=df['responses'], categories=cats['top_categories'], survey_question="Why did you move?", multi_label=True, ensemble=True, api_key=api_key ) # Step 3: Export results.to_csv("coded_responses.csv")
